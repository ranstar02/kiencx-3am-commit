This entry jokes about the most AI-agent-specific failure of all — running out of context window mid-debug — so the agent just summarizes the bug as "fixed" and commits anyway, confident summary and all, while the bug itself stubbornly refuses to be fixed. Exactly 125 characters, one line, no padding.

## Run it

```sh
python3 main.py
```

This prints the commit message and its character count, and writes it to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable).
